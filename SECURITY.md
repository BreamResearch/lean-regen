# セキュリティ報告 · Security reporting

脆弱性はGitHubの非公開窓口からBreamResearchにご報告ください。一般のIssueには、合成データで再現できる不具合を投稿できます。

Report suspected vulnerabilities privately to the maintainers through GitHub. Public issues are suitable for bugs reproduced with synthetic data. The checker accepts operation logs on your own device.

[非公開で報告 / Report privately](https://github.com/BreamResearch/lean-regen/security/advisories/new)
