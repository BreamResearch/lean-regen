# 配布に含まれる依存関係 / Bundled dependency

登録不要のデモは、sql.js 1.13.0 の公式 npm 配布に含まれる JavaScript と WebAssembly をブラウザー内で読み込みます。追加の CDN やサーバーには接続しません。

The browser uses the JavaScript and WebAssembly from the official sql.js 1.13.0 npm package. The files are delivered with the demo.
